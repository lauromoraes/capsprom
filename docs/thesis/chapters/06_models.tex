\chapter{Models}\label{chap:models}

\section{Baseline Models}\label{sec:models-baselines}

Baseline models provide reference performance for evaluating proposed
architectures. Candidate baselines include classical machine learning models,
CNNProm-style convolutional networks, GraphPro-inspired approaches, and
transformer-based promoter models where feasible. Neural-network notation and
model descriptions follow the distinction between data representations, model
functions, trainable parameters, and objective functions commonly used in
deep-learning methodology~\citep{goodfellow2016deep}. In this thesis, DNA-BERT has
two planned roles: it may provide sequence embeddings for other classifiers, and
it may also be fine-tuned as an end-to-end promoter classifier with a binary
classification head. The latter role belongs to the model-development stage and
is intentionally kept separate from the feature-engineering encoder.

\section{CapsProm}\label{sec:models-capsprom}

In this thesis, CapsProm denotes the basic binary capsule architecture with two
output capsules: one represents the non-promoter class and the other represents
the promoter class. Primary capsules can consequently distribute their coupling
between competing class capsules, making routing-by-agreement operational. Capsule equations in this chapter
follow the notation of \citet{sabour2017dynamic} and describe a single input,
so the example index is omitted and $i$ and $j$ index capsules. Let
$\mathbf{v}_0$ and $\mathbf{v}_1$ denote the non-promoter and promoter output
capsules. The positive-class score of Equation~\eqref{eq:bg-score} is the
relative capsule length
\begin{equation}
  f\bigl(\Phi(x);\boldsymbol{\theta}\bigr)=\frac{\lVert\mathbf{v}_1\rVert}{\lVert\mathbf{v}_0\rVert+\lVert\mathbf{v}_1\rVert},
  \label{eq:models-capsule-score}
\end{equation}
which is set to $0.5$ when both lengths are zero. This score is not a calibrated
probability. The class prediction is the output capsule with the largest
vector norm, which equals the decision rule of Equation~\eqref{eq:bg-decision}
with $t^{\star}=0.5$, except that an exact tie is assigned to the
non-promoter class. The reconstruction branch is conditioned on the true class during
training and on the predicted class during inference. In the canonical
implementation, the votes used to update agreement logits in intermediate
routing iterations are detached from the computational graph, while gradients
are propagated through the final capsule computation. This policy avoids
backpropagation through the iterative routing-state updates and is recorded
explicitly in each versioned experimental configuration.

For reconstruction, the non-selected class capsule is set to zero and the
complete masked two-capsule tensor is flattened before entering the decoder.
The auxiliary objective is the mean across samples of the summed squared error
over nucleotide positions and channels, scaled by (0.0005). This retains the
class-specific decoder slots and the reconstruction-loss convention of the
seminal CapsNet rather than treating the selected capsule as an unlabelled
16-dimensional vector.

The earlier published implementation used a single output capsule. This legacy
CapsProm-1C model is retained only for historical reproduction under the unified
protocol and for analysis of the original methodology. Because its routing
softmax has only one possible destination, every coupling coefficient equals
one; it is therefore not treated as the basic CapsProm model or as an active
architecture-development candidate in this thesis.
